TrackSphere is a cloud-based shipment tracking platform built for freight forwarders, logistics operators, and e-commerce businesses. It gives your customers real-time visibility into every shipment — by sea, air, or road — with instant notifications, smart analytics, and a fully branded tracking experience. Below is a complete list of platform features grouped by category.

1
Core capability
Real-Time Shipment Tracking
📡
Live shipment status updates
Track shipments in real time across all major carriers — ocean, air, road, and rail. Status refreshes automatically as events are received from the carrier.
Core
🗺️
Interactive world map view
See every active shipment plotted on a live map with vessel positions, flight paths, truck routes, and port/airport stops clearly visualised.
Core
📋
Full event timeline & history
Every carrier scan, location checkpoint, customs clearance, and delivery attempt is recorded with an exact timestamp, location, and event description.
Core
🔢
Multi-carrier support
Natively integrated with Maersk, MSC, CMA CGM, DHL, FedEx, UPS, Evergreen, and more. One platform tracks all your carriers in a single dashboard.
Core
📱
Public customer tracking portal
A branded, shareable tracking page where your customers simply enter a tracking number or scan a QR code — no account or login required.
Core
⏱️
Estimated time of arrival (ETA)
Dynamic ETA displayed at every stage of the journey, automatically updated when the carrier reports a delay or schedule change.
Core
🧠
AI-powered ETA prediction
Machine learning model trained on historical shipment data predicts delay probability, revised arrival windows, and customs clearance time with a confidence score.

3
Operations
Exception & Delay Management
🚨
Automatic exception detection
The system automatically flags exceptions — customs holds, missed connections, long dwell times, blank sailings, and no-update anomalies — as soon as they occur.
Core
🏷️
Root cause tagging
Ops agents tag each exception with a root cause category (documentation, customs duty, carrier delay, weather, port congestion) for tracking and reporting.
Growth
📌
Exception queue & assignment
All active exceptions surface in a dedicated queue, assignable to the responsible ops agent with an expected resolution date and internal notes.
Growth
📏
SLA monitoring & escalation
Define service level targets per lane or carrier. The system tracks SLA compliance and auto-escalates unresolved exceptions to a manager after a set period.
Growth

Business intelligence
Analytics & Reporting
📊
Operations dashboard
A live overview of all shipments with key KPIs: on-time delivery rate, average transit days, number of active exceptions, and shipment count by mode and carrier.
Core
🏎️
Carrier performance benchmarking
Compare carriers side-by-side on on-time rate, average transit time, and exception frequency for any lane and date range. Make smarter carrier selection decisions.
Growth
🗺️
Lane analytics
Analyse performance by trade lane (e.g. Douala → Rotterdam). Identify which routes have the most delays, highest costs per day late, and worst exception rates.
Growth
📅
Scheduled report delivery
Set up automated weekly or monthly PDF or CSV reports that are generated and emailed to your team or management on a fixed schedule — no manual work needed.
Growth
⬇️
CSV & PDF export
Export any dataset — shipment list, event history, exception log, carrier performance — as a CSV for BI tools or as a formatted PDF for client presentations.
Core
🌿
Carbon emissions tracking
Automatically estimates CO₂ emissions per shipment by transport mode and distance. Generates ESG-ready carbon reports increasingly required by European shippers.

Trust & compliance
Security & Data Protection

TrackSphere is built security-first. All data is encrypted at rest and in transit. Each customer's data is completely isolated from other accounts. The platform is designed for GDPR compliance and is on the SOC 2 Type II certification roadmap.

🔒
AES-256 encryption at rest
All shipment data, documents, and customer records stored with military-grade encryption.
Core
🛡️
TLS 1.3 in transit
All API calls, web traffic, and database connections secured with the latest TLS standard.
Core
🧱
Multi-factor authentication (MFA)
TOTP-based MFA available for all users, mandatory for admin accounts to protect against credential compromise.
Core
🌐
Cloudflare WAF & DDoS protection
Enterprise-grade firewall and DDoS mitigation protecting the platform 24/7 with 99.9% uptime SLA.
Core
🗑️
GDPR data deletion on request
Full right-to-erasure workflow. Any customer's personal data can be permanently purged within 72 hours of request.
Core
💾
Automated daily backups
Automated database backups taken daily with 30-day retention and point-in-time restore capability.
